# Контракт CSV для согласования с 1С

Статус: экспорт реализован; импорт в конкретную конфигурацию 1С партнёра не подтверждён. Этот документ описывает фактический формат для настройки и проверки загрузки специалистом 1С. Готовой обработки 1С в проекте нет.

## Формат

GET /api/orders/{id}/export доступен после утверждения. Кодировка UTF-8 с BOM, разделитель `;`, строки CRLF, внутренние кавычки удваиваются. Числа с десятичной точкой, без разделителей тысяч. Цена в тенге, минимум 1; дробные цены от 1 допустимы. Сумма округлена до двух знаков. Количество проверено по минимуму и кратности партии.

| Колонка | Содержание |
|---|---|
| Код 1С | Ключ номенклатуры; импортировать строкой, сохраняя ведущие нули |
| Артикул поставщика | Исходный или подтверждённый менеджером артикул |
| Поставщик | Наименование поставщика выбранного набора |
| Наименование | Название товара |
| Ед. | Исходная или подтверждённая единица |
| Количество | Утверждённое количество |
| Цена | Подтверждённая цена за единицу |
| Сумма | Количество × цена |
| Обоснование | Расчёт рекомендации; после ручной правки итог берётся из Количество |
| Срочность | Высокая, Средняя или Плановая |

Один CSV содержит выбранные строки одного утверждённого заказа одному поставщику. Ручные уточнения реквизитов сохраняются в JSON заказа как manual_requisites с исходным и подтверждённым значениями. CSV содержит итоговые значения. Строки с формульными префиксами экранируются апострофом; обработчик должен учитывать это соглашение, не удаляя произвольно апострофы из идентификаторов.

## Приёмка в тестовой базе партнёра

1. Уточнить версию и конфигурацию 1С, документ назначения, обработчик импорта, справочники контрагентов/единиц, правила НДС и точность чисел. Эти параметры не предоставлены.
2. Сопоставить Код 1С с существующей номенклатурой и поставщика с контрагентом. Не создавать дубли по одному лишь названию.
3. Загрузить утверждённый тестовый заказ; проверить ведущие нули, кириллицу, дробные цены/количества, кавычки и точку с запятой в названии.
4. Сверить строки и сумму с JSON сохранённого заказа. Повторный импорт не должен незаметно создавать второй документ.
5. Записать версии, SHA проекта, настройки сопоставления и фактический результат. До этого говорить «CSV для обмена», не «проверенная интеграция с 1С».

Отправка поставщику и автоматическое проведение документа 1С не выполняются.
