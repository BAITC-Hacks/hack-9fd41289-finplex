## Среда и инструменты

- Python 3.11–3.12: интерпретатор и стандартная библиотека; [первичный источник](https://github.com/python/cpython), LICENSE в дистрибутиве.
- Docker-образы python:3.11-slim и nginx:1.27-alpine заданы в Dockerfile; [описания официальных образов](https://github.com/docker-library/docs). Это составные дистрибутивы с лицензиями своих компонентов, не одна лицензия проекта. Backend дополнительно устанавливает curl. Лицензионные материалы поставляются соответствующими образами/пакетами; их не удаляют инструкции проекта.
- Git/GitHub — контроль версий; Docker/Compose — сборка и запуск; Node.js — проверки JavaScript. Для работы страницы Node.js не нужен: frontend использует HTML/CSS и браузерный JavaScript без стороннего JS-фреймворка.
- pytest и Ruff используются только при разработке и проверке.

## Данные

Двенадцать Excel-файлов в data/systeme и data/iek — исходные материалы кейса ТОО «Электрокомплект», предоставленные для HackAlem AI. Команда не заявляет авторство этих данных. Их включение в репозиторий соревнования не означает выдачу командой открытой лицензии на их дальнейшее распространение.

Синтетические данные в тестах созданы для проверки сценариев. Реальные stockout-интервалы и обезличенные ID клиентов в приложенных наборах отсутствуют. Входной customer_id должен быть заранее обезличен; ФИО/контакты нельзя подставлять вместо него.

## AI при разработке и в продукте

В подтверждённой работе над репозиторием использовался OpenAI Codex: анализ кода и требований, подготовка исправлений, тестов и документации, выполнение проверок и публикация по поручению команды. AI-помощь не заменяет вклад и ответственность участников. Перечень иных ранее применённых инструментов команда дополняет по факту; этот документ не утверждает, что их не было.

В работающем продукте расчёт количеств детерминированный, без обязательной внешней модели. Опциональная LLM-обёртка поддерживает OpenAI-совместимый API и модель из LLM_MODEL; по умолчанию вызовы выключены. При включении передаются только агрегированные числа позиций/рисков для текста резюме. Модель не рассчитывает заказ; при ошибке API действует локальное резюме. Для проверки основного сценария эксперту не нужен личный AI-аккаунт.

Сторонние компоненты сохраняют собственные лицензии. Этот перечень не переоформляет права на них или на материалы партнёра.
